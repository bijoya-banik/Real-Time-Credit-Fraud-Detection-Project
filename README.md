## Required Files

Some files required to run the project are provided separately because of
GitHub file-size and security restrictions.

### 1. Dataset

The original credit card fraud detection dataset is provided separately.

Download Dataset from:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud or
https://drive.google.com/file/d/1SeIUIYfEWGin3Umu2LHKnv1MDZnAIJJ-/view?usp=drive_link

After downloading, place the dataset in:
Real Time Credit Fraud Detection Project/azure-fraud-detection/data/creditcard.csv

### 2. Azure Credentials

The Azure credentials required to run the real-time streaming and fraud
detection components are provided separately.

Download Credentials from:
https://drive.google.com/file/d/1KY9mR6RORXbiG-k3BfGrhFTh1xZ8QfwN/view?usp=sharing

After downloading, place the file in the project root directory:

credentials.txt

For security reasons, the credentials file is not included in the GitHub
repository.
